第1週：R 環境建置與資料匯入

安裝、介面認識、基本操作、匯入 ems_main.csv

本週學習目標

完成本週後，你應該能夠：

  1. 完成 R 與 RStudio 的安裝
  2. 認識 RStudio 四個面板的功能
  3. 執行基本的 R 語法
  4. 將 ems_main.csv 匯入 R 並檢視資料結構

1. 安裝 R 與 RStudio

重要

安裝順序很重要：先裝 R，再裝 RStudio。 RStudio 是操作介面，R 才是真正的引擎。

安裝 R

  1. 前往 https://cran.r-project.org/
  2. 點選你的作業系統（Windows / macOS）
  3. 下載最新版本（目前 R 4.4.x）並安裝，全部選預設即可

安裝 RStudio

  1. 前往 https://posit.co/download/rstudio-desktop/
  2. 下載免費版 RStudio Desktop
  3. 安裝，全部選預設即可

安裝完成後，只需要開啟 RStudio，不需要另外開 R。

2. 認識 RStudio 介面

RStudio 開啟後你會看到四個面板：

面板位置 名稱 功能
左上 Script 編輯器 寫程式碼的地方，可以存檔
左下 Console 直接執行指令、看輸出結果
右上 Environment 顯示目前載入的物件與資料
右下 Files / Plots 檔案管理、圖表輸出
提示

建議習慣： 程式碼寫在 Script 編輯器（左上），不要直接在 Console 打。 這樣你的分析過程可以存檔、重現、修改。

3. 第一個 R 指令

在 Script 編輯器貼上以下程式碼，選取後按 Ctrl + Enter（Mac 用 Cmd + Enter）執行：

# 這是註解，R 不會執行 # 後面的文字
1 + 1

# 指定一個變數
x <- 10
y <- 3
x + y
x * y
x / y

# 文字
name <- "EMS統計課"
print(name)
註釋

<- 是 R 的賦值符號，意思是「把右邊的值存入左邊的變數」。 也可以用 =，但 R 慣例用 <-。 快捷鍵：Alt + -（Mac 用 Option + -）

4. 安裝與載入套件

R 的強大來自套件（packages）。本課程主要用到以下套件，第一次使用前需要安裝：

# 安裝套件（每台電腦只需要做一次）
install.packages("tidyverse")   # 資料整理與視覺化
install.packages("ggplot2")     # 圖表（已包含在 tidyverse）
install.packages("dplyr")       # 資料操作（已包含在 tidyverse）
install.packages("car")         # Levene's test 等
install.packages("effectsize")  # 效果量計算
install.packages("lavaan")      # SEM（第14週）
install.packages("gee")         # GEE（第12週）
# 載入套件（每次開啟 RStudio 都要執行一次）
library(tidyverse)
library(ggplot2)
library(dplyr)
重要

install.packages() 是下載安裝，只做一次。 library() 是載入啟用，每次開新的 R session 都要做。 這是初學者最常搞混的地方。

5. 資料類型

R 有幾種基本資料類型，對應到統計上的變項類型：

# 數值（連續變項）
age <- 34
response_time <- 8.5

# 字串（類別變項的原始輸入）
gender <- "男"
level  <- "EMT-P"

# 因子 factor（類別變項的正確格式）
level_f <- factor(level, levels = c("EMT-1", "EMT-2", "EMT-P"))

# 邏輯值
is_senior <- age > 40
print(is_senior)   # FALSE

# 確認資料類型
class(age)           # "numeric"
class(gender)        # "character"
class(level_f)       # "factor"
提示

統計分析前一定要確認： 類別變項（性別、職級、地區）在 R 裡必須是 factor， 不然很多統計函數會報錯或給出錯誤結果。

6. 匯入主資料集

本課程全學期使用同一份資料：ems_main.csv。

步驟

  1. 將 ems_main.csv 放入你的專案資料夾（建議放在 data/ 子資料夾）
  2. 執行以下程式碼：
# 匯入 CSV 資料
ems <- read.csv("data/ems_main.csv", 
                fileEncoding = "UTF-8",
                stringsAsFactors = FALSE)

# 確認資料維度
dim(ems)          # 顯示「列數 欄數」，應為 200 27

# 看前六列
head(ems)

# 看資料結構
str(ems)

# 基本摘要
summary(ems)

將類別變項轉為 factor

# 匯入後立刻做這個步驟，往後分析才正確
ems$gender   <- factor(ems$gender, levels = c("男","女"))
ems$level    <- factor(ems$level,  levels = c("EMT-1","EMT-2","EMT-P"))
ems$district <- factor(ems$district, 
                        levels = c("北部","中部","南部","東部"))
ems$shift    <- factor(ems$shift, 
                        levels = c("日班為主","夜班為主","輪班"))

# 確認轉換結果
str(ems)
levels(ems$level)    # 應顯示 "EMT-1" "EMT-2" "EMT-P"
