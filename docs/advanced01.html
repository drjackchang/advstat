為什麼需要存活分析？

一般統計方法的限制

假設你想研究「OHCA 患者從倒下到 ROSC 的時間」， 你可能會想用 t 檢定比較兩組的平均時間。 但這裡有一個問題——

重要

設限資料（Censored Data）的問題

在研究結束時，有些患者：

  • 還沒有達到研究終點（ROSC）就出院或轉院
  • 在觀察期間死亡（但不是因為 OHCA）
  • 失去追蹤

這些觀察值不能直接丟棄（會造成偏誤）， 也不能當作沒有發生事件來處理。

一般的 t 檢定或回歸無法正確處理這種資料， 存活分析才能。

存活分析的三個核心概念

1. 存活時間（Survival Time）

從研究開始到事件發生的時間： - OHCA 從倒下到 ROSC 的時間 - EMS 人員從到職到離職的年資 - 患者從急救到死亡的時間

2. 事件（Event）

研究者感興趣的結果，通常是負面事件： - OHCA 死亡 - EMS 人員離職 - 職業傷害再發

3. 設限（Censoring）

觀察結束時，事件還沒有發生的情況：

時間軸：
受試者A：|------事件------|          （完整資料）
受試者B：|----------研究結束          （右設限：研究結束時還沒發生事件）
受試者C：|------轉院/失聯             （右設限：中途失追蹤）

一、統計理論

1.1 存活函數 S(t)

\[S(t) = P(T > t)\]

在時間點 t，還沒有發生事件的機率。

  • S(0) = 1（一開始所有人都存活）
  • S(∞) = 0（最終所有人都會發生事件）
  • S(t) 是單調遞減函數

EMS 例子： S(30) = 0.65 代表「急救開始後 30 分鐘， 65% 的 OHCA 患者仍未達到 ROSC」

1.2 風險函數 h(t)

\[h(t) = \lim_{\Delta t \to 0} \frac{P(t \leq T < t + \Delta t | T \geq t)}{\Delta t}\]

在時間點 t，已經存活到 t 的人， 在接下來極短時間內發生事件的瞬時速率。

  • h(t) 越高 → 這個時間點越「危險」
  • 用於 Cox 模型

1.3 Kaplan-Meier 估計法

非參數方法，不假設資料服從特定分布， 直接從資料估計存活函數：

\[\hat{S}(t) = \prod_{t_i \leq t} \left(1 - \frac{d_i}{n_i}\right)\]

  • \(d_i\)：在時間點 \(t_i\) 發生事件的人數
  • \(n_i\)：在時間點 \(t_i\) 之前還在風險中的人數（risk set）

直觀理解： 每次有人發生事件，存活機率就下降一步， 形成「階梯狀」的存活曲線。

1.4 Log-rank Test

比較兩組或多組的存活曲線是否有顯著差異。

H₀：各組的存活函數相同（存活曲線重疊）

\[\chi^2 = \frac{(O_1 - E_1)^2}{E_1} + \frac{(O_2 - E_2)^2}{E_2}\]

  • O = 觀察到的事件數
  • E = 在 H₀ 下期望的事件數
  • df = 組數 − 1
提示

Log-rank test 對所有時間點給予相等的權重， 適合組間差異在整個追蹤期間都穩定的情況。

若早期差異較大，可改用 Wilcoxon（Breslow）檢定。

1.5 Cox 比例風險模型

存活分析版本的「回歸」——可以同時控制多個預測變項：

\[h(t|X) = h_0(t) \cdot \exp(\beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_k X_k)\]

  • \(h_0(t)\)：基準風險函數（baseline hazard）
  • \(\exp(\beta_j)\)：風險比（Hazard Ratio, HR）

風險比（HR）的詮釋：

HR 值 意義
HR = 1 X 對事件風險無影響
HR > 1 X 增加 → 事件風險增加
HR < 1 X 增加 → 事件風險降低（保護因子）
HR = 2 X 每增加 1 單位，事件風險變為原來的 2 倍
HR = 0.5 X 每增加 1 單位，事件風險降低 50%
重要

比例風險假設（Proportional Hazards Assumption）

Cox 模型假設各組之間的風險比在整個追蹤期間是固定的 （兩組的存活曲線不會交叉）。

違反此假設時，需要加入時間交互作用項或改用其他方法。

診斷：Schoenfeld 殘差圖、cox.zph() 函數。

二、分析流程

Step 1：確認資料格式（時間變項 + 事件變項）
    ↓
Step 2：描述統計（各組事件發生率、中位存活時間）
    ↓
Step 3：Kaplan-Meier 存活曲線
    ↓
Step 4：Log-rank test（組間比較）
    ↓
Step 5：Cox 比例風險模型（控制共變項）
    ↓
Step 6：比例風險假設檢查
    ↓
Step 7：APA 格式報告

  id       = 1:n,

註釋

如何閱讀 KM 曲線：

  • Y 軸：存活機率 S(t)，從 1.0 開始往下
  • X 軸：追蹤時間
  • 每次階梯下降：有事件發生
  • 垂直短線（+）：設限觀察值
  • 陰影區域：95% 信賴區間
  • 中位存活時間：曲線與 S(t) = 0.5 水平線的交點

Cox 比例風險模型

執行 Cox 模型

cox_model <- coxph(
  Surv(time, status) ~ unit_type + age +
    bystander + response_min,
  data = ohca
)

cox_sum <- summary(cox_model)

四、結果報告範例（APA 格式）

Kaplan-Meier + Log-rank test：

以 Kaplan-Meier 法估計各救護配置類型的 OHCA 存活曲線。 ALS 配置組的中位存活時間（35.2 分鐘） 顯著長於 BLS 配置組（24.8 分鐘）。 Log-rank test 顯示兩組存活曲線有顯著差異， χ²(1) = 8.43，p = .004。

Cox 比例風險模型：

Cox 比例風險模型同時控制年齡、旁觀者 CPR 與到院反應時間後，ALS 配置顯著降低 OHCA 死亡風險 （HR = 0.62，95% CI [0.45, 0.86]，p = .004）， 顯示 ALS 配置相對於 BLS 配置， 可使事件風險降低約 38%。 旁觀者 CPR 亦為顯著保護因子 （HR = 0.71，95% CI [0.53, 0.95]，p = .021）。 比例風險假設檢查顯示假設成立（全體模型 p = .312）。
