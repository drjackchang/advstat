為什麼需要空間回歸？

地理資料的特殊性

一般統計方法假設觀察值之間相互獨立。 但地理資料違反這個假設——

重要

Tobler 地理學第一定律：

「所有事物都與其他事物相關， 但近的事物比遠的事物更相關。」

— Waldo Tobler, 1970

EMS 的空間問題：

  • 台北市某行政區的 OHCA 存活率高， 鄰近行政區的存活率也傾向較高
  • 某地區的 EMS 反應時間受鄰近地區的交通狀況影響
  • 職業傷害率可能有地理群聚現象

如果用一般 OLS 回歸分析這類資料，殘差會有空間自相關， 導致標準誤低估、p 值失真。

一、統計理論

1.1 空間自相關

正空間自相關： 相似的值聚集在一起（高高聚集、低低聚集）

負空間自相關： 不相似的值相鄰（棋盤格狀分布）

空間隨機： 值的分布與地理位置無關

1.2 空間權重矩陣 W

空間權重矩陣定義「哪些地區算是鄰居」：

鄰接權重（Contiguity）：

\[w_{ij} = \begin{cases} 1 & \text{如果 i 和 j 共享邊界} \\ 0 & \text{其他} \end{cases}\]

通常進行列標準化，讓每列的權重加總為 1。

1.3 Moran’s I

\[I = \frac{N}{\sum_i \sum_j w_{ij}} \cdot \frac{\sum_i \sum_j w_{ij}(x_i - \bar{x})(x_j - \bar{x})}{\sum_i (x_i - \bar{x})^2}\]

Moran’s I 值 解讀
接近 +1 強正空間自相關（相似值聚集）
接近 0 空間隨機分布
接近 −1 強負空間自相關

1.4 空間回歸模型

空間滯後模型（SLM）：

\[Y = \rho WY + X\beta + \varepsilon\]

  • ρ：空間自相關係數
  • 假設：Y 的值受鄰居 Y 值的影響

空間誤差模型（SEM）：

\[Y = X\beta + u, \quad u = \lambda Wu + \varepsilon\]

  • λ：誤差的空間自相關係數
  • 假設：有未觀測的空間因素影響 Y

如何選擇：

先跑 OLS
    ↓
Moran's I 檢定殘差
    ├── 不顯著 → OLS 足夠
    └── 顯著 → 看 Lagrange Multiplier 檢定
                ├── LM-lag 顯著 → SLM
                ├── LM-err 顯著 → SEM
                └── 兩者都顯著 → 用 robust LM 結果

載入套件與建立模擬資料

library(tidyverse)
library(gt)
library(spdep)
library(spatialreg)

set.seed(2025)
n_district <- 25

# 建立 5x5 網格坐標模擬行政區
coords <- expand.grid(x = 1:5, y = 1:5)
coords$district_id <- 1:n_district

# 建立有空間自相關的模擬資料
spatial_effect <- rnorm(n_district, 0, 2)

for (iter in 1:20) {
  for (i in 1:n_district) {
    xi <- coords$x[i]
    yi <- coords$y[i]
    neighbors <- which(
      abs(coords$x - xi) <= 1 &
      abs(coords$y - yi) <= 1 &
      (1:n_district) != i
    )
    if (length(neighbors) > 0) {
      spatial_effect[i] <-
        0.6 * mean(spatial_effect[neighbors]) +
        0.4 * spatial_effect[i]
    }
  }
}

district_data <- data.frame(
  district_id   = 1:n_district,
  x             = coords$x,
  y             = coords$y,
  ohca_survival = pmin(100, pmax(0,
    50 + spatial_effect * 5 +
    rnorm(n_district, 0, 5))),
  response_time = pmin(20, pmax(3,
    10 - spatial_effect * 0.8 +
    rnorm(n_district, 0, 2))),
  hospital_dist = pmin(15, pmax(1,
    8 + rnorm(n_district, 0, 3))),
  ems_density   = pmin(10, pmax(1,
    5 + spatial_effect * 0.5 +
    rnorm(n_district, 0, 1.5))),
  population_65 = pmin(30, pmax(5,
    15 + rnorm(n_district, 0, 5)))
)

cat("資料概覽：n =", nrow(district_data), "個行政區\n")

三、結果報告範例（APA 格式）

空間自相關檢定：

Moran’s I 檢定顯示各行政區 OHCA 存活率 具有顯著正空間自相關， I = 0.42，z = 3.18，p = .001， 表示存活率高的行政區傾向與其他高存活率地區相鄰， 直接使用 OLS 回歸將違反獨立性假設。

空間回歸模型：

鑑於 OLS 殘差存在顯著空間自相關， 改以空間滯後模型（SLM）進行分析。 空間自相關係數 ρ = 0.48（p < .001）， 顯示鄰近行政區的 OHCA 存活率對本地存活率有顯著正向影響。 控制空間效應後，到院反應時間顯著負向預測存活率 （B = −2.31，p = .008）， EMS 站點密度顯著正向預測存活率 （B = 3.14，p = .021）。 SLM（AIC = 142.3）優於 OLS（AIC = 158.7）。
